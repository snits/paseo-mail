# Plugin SDK version 0.16

Status: Accepted

## Context

Cross-host mail (`2026-11-21-cross-host-delivery.md`) writes agent metadata through
`agents.ref(id).setMetadata`. That method is absent from `@getpaseo/client` 0.15.3, the client
under `@getpaseo/plugin` 0.15.3. It is present in 0.16.2, and the 0.16.2 server advertises the
`entityMetadata` feature it needs. Both hosts the plugin runs on run Paseo 0.16.2.

## Decision

- This supersedes `2026-11-10-sdk-version.md`.
- Build against `@getpaseo/plugin` 0.16.2.
- Require Paseo `>=0.16.2` in `paseo-plugin.json`. Jerry ruled this (kata paseo-mail#m2f2).

## Consequences

- The plugin does not load on Paseo 0.15.
